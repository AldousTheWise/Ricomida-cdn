# 🍔 Ricomida-CDN

**Ricomida-CDN** es un sitio web estático diseñado para mostrar la presentación de una marca de comida. Se enfoca en un diseño atractivo y una maquetación responsiva usando CDN para facilitar su implementación.

## 🚀 Tecnologías Utilizadas

- HTML5  
- CSS3 
- JQuery 
- Bootstrap CDN  
- Google Fonts  
- Imágenes optimizadas  

## 📂 Estructura del Proyecto

```bash
ricomida-cdn/
│── index.html       # Página principal
│── styles.css       # Estilos personalizados
│── images/          # Carpeta con imágenes del sitio
│── README.md        # Documentación del proyecto
```
